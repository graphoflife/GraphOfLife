Graph of Life

An Artificial Life Algorithm

An attempt at finding Open Ended Evolution with graph theory, evolutionary game theory and neural networks. No optimization — just mutation, evolution and natural selection.

The whole script is on the right and runs on its own — python3 explain_minimal.py. The graph is a real run: seed 5 from iteration 129, chosen because every mechanic fires in it.

Nodes
Additive: it builds up where nodes crowd together, and needs a dark background and a colour brighter than it to show. A black outline colour glows not at all.

Edges

Background
The edge key appears once edges are coloured by something — a flat colour has no range, and inheriting the node colour would repeat the key above it.

Layout
All-pairs, so the graph spreads globally. At 0 only the springs act and it clumps tightly. Spreads each node's edges evenly — 180° at degree 2, 120° at degree 3. How closely all-pairs repulsion is approximated. Lower is more exact and much slower; the cost falls with the cube of this. Raise it on very large graphs.

Presets

Lineage

Every genotype a run ever held, as a line: from the frame it first appeared in to the last one it was seen in, thickening with how many agents carried it, joined to the genotype it mutated from. Clades sit together, so a family is a band.

Colour is ancestry. A founder is given a colour at random and every mutation nudges its parent’s, so relatedness is visible directly — and a run that ends one colour is a run where one founder’s descendants took the world.
